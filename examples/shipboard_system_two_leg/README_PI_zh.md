# 单台逆变器电压幅值 PI

这是在正式两腿 DC/DC 船舶模型上增加的独立闭环试验。HPP、电路参数和前向 Euler 不变；控制器在求解器外部根据逆变器 1 输出电压计算 SPWM 调制度。其余五台逆变器启动后保持 m=1。

## 控制

每 50 ns 推进电路、累加三相电压；每 10 µs 取前一个完整载波周期的均值，再计算 Clarke 幅值并低通。先平均后取模能抑制开关纹波；Clarke 去除零序，不把三相共模电压算作正序幅值。平衡正弦下，这个量接近相电压峰值，不是相电压 RMS。

```text
alpha = (2*mean(va)-mean(vb)-mean(vc))/3
beta = (mean(vb)-mean(vc))/sqrt(3)
Vmeasured = sqrt(alpha^2+beta^2)
Vfiltered += (1-exp(-Tc/tau))*(Vmeasured-Vfiltered)
e = (Vreference-Vfiltered)/6000
I_proposed = I + Ki*Tc*e
m = clamp(Kp*e+I, 0, 1)
```

参数：Tc=10 µs、tau=0.2 ms、Kp=0.2、Ki=600 /s。PI 没有母线前馈；10.133 s 改变的是参考值 6000→3000 V，闭环中没有直接把调制度乘 0.5。Ki=300/600/1000 /s 的短时试验均有界，最终选择中间值，滤后幅值的 2% 调节时间约 7 ms。

候选积分使输出继续越过上限且 e>0、或继续越过下限且 e<0 时冻结积分；反向误差允许积分，因而能够退出饱和。日志 `saturated` 包含积分被阻止，不能严格解释为每点 m 都等于 1。禁用时清零控制器和滤波器；约 4 ms 启用，参考在随后 2 ms 软启动。DC/DC 约 20 µs 开启并以 2 ms 软启动，实际首次使能为 20.05 µs，两电路步长仍采用同一 50 ns 门极网格。

## 对照结果

50 ns 下，闭环和匹配开环均从零初态运行到 10.2 s，各完成 2.04 亿步。开环也只改变逆变器 1，其他五台保持 m=1；上一轮六台同时降压的结果没有混入本次比较。

| 工况及统计窗口 | PI 滤后幅值均值 | 开环滤后幅值均值 |
|---|---:|---:|
| 3 kV 参考，10.17–10.20 s | 3000.04 V | 2988.85 V |
| 母线降压扰动后，0.22–0.25 s | 2999.87 V | 2490.65 V |

抗扰试验先在 0.133 s 将参考改为 3 kV，再在 0.163 s 将 DC/DC 占空比 0.8→0.75，使母线由约 ±6 kV 降至约 ±5 kV。PI 调制度自行增加到约 0.602，补偿电源下降；匹配开环维持 m=0.5。扰动瞬间仍有暂态振铃，随后衰减，上表报告的是晚期平均值。

6 kV 参考略高于本电路 m≤1 时的稳态可用输出，前段实际约 5977.54 V，残差约 22.46 V（0.37%）。这不是积分没有工作，而是调制上限限制；抗饱和使积分不会继续堆积。本例没有扩大调制上限，也没有暗改参考来消除此残差。

25 ns 短时对照沿用相同 50 ns 门极时钟、10 µs PI 周期与事件时刻。0.09–0.20 s 严格 2 µs 共有网格上的三相相对 RMS 差均小于 0.025%，滤后幅值相对 RMS 差约 0.003%。这验证短时步长敏感性，不是论文数据误差。

## 与论文的关系

2019 论文第 375–376 页 Fig.17/19 描述外部 TI F28335 对一台三相逆变器进行 PI 闭环。原文没有公开增益、控制采样率、反馈采用峰值/RMS/dq/瞬时电压的选择、测量滤波及限幅设置。因此本例是参照所控对象自行设计的**单逆变器电压幅值 PI**，不是恢复原作者 PI，也没有实现真实外部 HIL。100 kHz 开关频率来自论文；本例 100 kHz 控制采样率是自行选择，二者不能混为论文已公开的数据。

论文并列图比较降压幅度和暂态特征，具体相位、包络及纹波仍有差异；没有原始数值曲线，未计算对原图的 RMSE。原网表远端输入没有独立外部源等条件仍按基础示例保留。

## 复算

先按基础示例 README 构建支持两腿模型的 CLI，然后：

```powershell
python examples/shipboard_system_two_leg/run_pi.py --codegen build/two_leg_codegen/SolverCodegen.exe --compiler "D:/Program Files/Mingw/bin/g++.exe"
```

需要 NumPy、Matplotlib。默认输出 `build/shipboard_two_leg_pi_20261024/`，保留上一轮开环结果；其中有原样 HPP、三相 CSV、控制 CSV、运行与生成日志、分析 JSON、结果报告和图。可用 `--probe-only` 只跑短时调参，`--skip-probes` 复用已有调参结果，`--analyze-only` 只重新验证数据绘图。论文并列图可复用本机上一轮已渲染的参考页，仓库不附带论文图像。

关键文件：`pi_voltage_controller.hpp` 为控制器；`simulate_pi.cpp` 为周期平均、PWM及电路耦合；`run_pi.py` 为生成、编译、运行；`analyze_pi.py` 为数据验证、指标及图像。HPP 的 SHA-256 在运行前后检查一致，未对生成后的积分公式做补丁。

测试：

```text
cmake --build build/two_leg_codegen --target test_pi_voltage_controller
ctest --test-dir build/two_leg_codegen --output-on-failure
```

PI 回归覆盖 8 组检查，包括测幅、滤波、归一化、采样步、上下限抗积分、禁用复位，以及独立平均对象的阶跃和增益扰动；原两腿生成器的 5 项端到端回归也保留。
